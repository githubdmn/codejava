

# 🔹 Mock Interview Drill (Java/Spring Boot + JPA + Angular + Full-stack)

---

## **1. General Software Engineering & SDLC**

**Q1:** Walk me through your process when you get a new feature request — from requirements to deployment.
**Q2:** What are some best practices you follow for code reviews and Git workflow?
**Q3:** In Agile teams, how do you break down complex tasks into deliverables for a sprint?
**Q4:** Suppose you’re building a **banking transaction module**. How do you ensure reliability, scalability, and maintainability?

---

## **2. Java & OOP Design**

**Q1:** What are some key **OOP principles** you apply in ERP/business applications?
**Q2:** Give an example of a **Java design pattern** you’ve used recently. Why that one?
**Q3:** What’s the difference between **checked** and **unchecked** exceptions? When would you create a custom exception?
**Q4:** How do you ensure thread-safety in a **multi-user ERP system** where multiple operations can update balances simultaneously?

---

## **3. Spring Boot (Backend Core)**

**Q1:** What are the key benefits of using **Spring Boot** compared to plain Spring?
**Q2:** Can you explain **dependency injection** and how Spring implements it?
**Q3:** Difference between `@Component`, `@Service`, and `@Repository`. Why not just use `@Component` everywhere?
**Q4:** Explain the role of `@Configuration` and `@Bean`.
**Q5:** How do you handle **application configuration**? (Profiles, YAML, secrets, external configs)
**Q6:** Difference between `@RestController` and `@Controller`.
**Q7:** How does Spring Boot **autoconfiguration** work?
**Q8:** How does **Spring manage transactions** with `@Transactional`? Give a real-world example from a banking system.

---

## **4. JPA / Hibernate (Persistence Layer)**

**Q1:** What is ORM? Why use JPA/Hibernate instead of plain JDBC?
**Q2:** Explain **lazy vs eager fetching**. When would you use each?
**Q3:** Hibernate caches — what’s the **difference between first-level and second-level cache**?
**Q4:** What are the different **Entity states** in Hibernate? (Transient, Persistent, Detached, Removed)
**Q5:** How do you map relationships? Explain `@OneToOne`, `@OneToMany`, `@ManyToMany`.
**Q6:** What is the **N+1 query problem**? How do you fix it?
**Q7:** How do you optimize database queries in JPA? (Fetch joins, projections, batch fetching, query hints)
**Q8:** Imagine you’re building a **loan repayment system** — how would you design the entities (Loan, Customer, Payment) and ensure efficient queries?

## **5. REST API Design**

**Q1:** How do you design **REST APIs** following best practices? (naming, versioning, error handling)
**Q2:** Difference between **idempotent** and **non-idempotent** HTTP methods. Examples?
**Q3:** How do you handle **validation** in Spring Boot APIs? (`@Valid`, `@ControllerAdvice`)
**Q4:** How would you design an API for **customer invoices** in ERP? What endpoints would you expose?
**Q5:** How do you implement **pagination and filtering** in REST APIs with Spring Data?

## **6. Frontend (Angular Basics)**

**Q1:** How does Angular communicate with a Spring Boot backend?
**Q2:** How do you structure services and components in Angular to ensure reusability?

**Q4:** How do you implement **authentication** in Angular (with Spring Security backend)?
**Q5:** How do you handle **state management** (localStorage, NgRx, or services)?

**Q1:** How does **Spring Security** integrate with REST APIs?

**Q4:** How do you deploy a Spring Boot + Angular app into production? (build pipelines, packaging)
